# 大埤肉雞場周界排查 v4.3

無須 Node.js。解壓後開啟 `index.html`，連網載入 Leaflet、Turf 與 NLSC 圖磚，亦可上傳 GitHub Pages。

## 本次整合
- 申請土地周界依《大埤肉雞場_範圍與點位 (1).geojson》5 頂點建置。
- 一般 500m、學校 1,000m；排查外圈依周界動態重建，不需信任匯出圖形精度。
- 《大埤肉雞場_周界排查備份.json》的 25 筆自訂名稱與點位已內建。初次載入或 v4.2 升級時，自動補齊，既有本機同名標示優先。
- 地圖呈現有名稱的**近似點位**；查詢頁可編輯名稱、地圖定位。原始色塊邊界沒有包含在備份中，須重新掃描才能恢復。
- 紀錄頁將已命名點位計入，不把候選點位冒充已查證正式場所。掃描預覽清空後仍保留已命名點位。

## 注意
名稱及座標為使用者手動標記的初步資訊，不是官方地籍界址、實際用途認定或已證實的距離。建議升級前匯出 JSON 備份。
